STORE WEEKLY REPORT

門市報表製作

下拉選任一門市，產生士林式 9 張週報（含個人項目動態填入）。EPB 即時查詢，免登入。

⬇ 下載啟動檔

下載後雙擊即可，會自動安裝到桌面並自動更新。

使用步驟

  1. 連上公司 VPN（需能連到 192.168.1.177）
  2. 雙擊剛下載的 啟動門市報表製作.command
    首次會被 macOS 攔下：在檔案上按右鍵 →「打開」→ 再按「打開」一次即可（之後從桌面雙擊不會再跳）。
  3. 稍候會自動開啟瀏覽器 http://127.0.0.1:8783/
  4. 下拉選門市、選週結束日期（週六）→ 按「產生報表」→ 下載 Excel

關閉黑色終端機視窗即停止。下次直接雙擊桌面資料夾「門市報表製作-app」裡的同名檔，會自動更新到最新版。

進階：用指令安裝（備援）

若雙擊方式不順，可開「終端機」貼上這行：

curl -fsSL https://raw.githubusercontent.com/samwang38/store-report/main/install.sh | bash
